# 🚦 مدونة السير المغربية — المساعد القانوني الذكي

تطبيق ويب احترافي يعمل بالكامل دون اتصال بالإنترنت، مخصص للمساعدة في فهم القوانين المرورية المغربية.

---

## 📁 هيكل الملفات

```
moroccan-traffic-law/
├── index.html          ← الصفحة الرئيسية (كل الواجهة)
├── style.css           ← نظام التصميم الكامل (Dark/Light Mode)
├── app.js              ← منطق التطبيق الكامل
├── manifest.json       ← إعدادات PWA
└── data/
    └── infractions.json ← قاعدة بيانات المخالفات
```

---

## ✨ المميزات

### 🔍 البحث الذكي
- بحث بالعربية والفرنسية في نفس الوقت
- تصفية حسب فئة المخالفة (خطيرة / متوسطة / بسيطة)
- عرض فوري للنتائج مع تفاصيل الغرامة والنقاط

### ⚖️ تحليل الحوادث (Rule-Based)
- نظام أسئلة وأجوبة لتحديد المخالفة
- تحديد المسؤولية القانونية
- نصائح قانونية استرشادية

### 🧮 حاسبة النقاط
- إضافة متعددة مخالفات وحساب مجموع النقاط المخصومة
- مؤشر حالة الرخصة (آمن / تحذير / خطر)
- حفظ الحسابات في LocalStorage

### 📖 مدونة السير
- أهم المواد القانونية بالعربية
- قابلة للتوسيع بالنقر

### 🌙 Dark / Light Mode
- تبديل فوري مع حفظ التفضيل

## 🚀 طريقة الاستخدام

1. **تشغيل محلي:** افتح `index.html` مباشرة في المتصفح
2. **خادم محلي (مُوصى به):**
   ```bash
   # Python
   python -m http.server 8080
   
   # Node.js
   npx serve .
   
   # VS Code: Live Server Extension
   ```
3. افتح `http://localhost:8080` في المتصفح

## 🔧 إضافة مخالفات جديدة

في `data/infractions.json` أضف عنصراً جديداً:

```json
{
  "id": 16,
  "title": "اسم المخالفة بالعربية",
  "title_fr": "Nom en français",
  "article": "المادة XX",
  "article_fr": "Article XX",
  "fine": 500,
  "points": 2,
  "category": "متوسطة",
  "category_fr": "Moyenne",
  "severity": "medium",
  "keywords": ["كلمة1", "كلمة2", "mot-clé"],
  "description": "وصف بالعربية",
  "description_fr": "Description en français"
}
```

**قيم `severity`:** `critical` | `high` | `medium` | `low`

## 📱 تحويل إلى PWA

1. أضف أيقونة PNG 192x192 واسمها `icon-192.png`
2. في `app.js`، فعّل تسجيل Service Worker:
   ```js
   navigator.serviceWorker.register('/sw.js')
   ```
3. أنشئ `sw.js` لتخزين الملفات في الكاش
